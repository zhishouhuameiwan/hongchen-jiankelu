# 手玩 QA 清单：完整通关主线

用于每次改动主线事件、地图引导、战斗结算、物品/装备/烹饪后快速手动回归。

## 准备

- 运行 `npm run dev`，打开本地预览页。
- 从主菜单开始新游戏，任意出身均可；推荐“游侠剑客”以减少战斗压力。
- 若浏览器已有旧存档，先清除存档后重新开始。

## 通关路径

- [ ] 新游戏进入地图后，当前目标显示“第一章：去青石镇接镖局悬赏，攒银两添置兵器。”
- [ ] 地图最多只显示 3 张可触发地点卡；没有可触发事件的地点不应显示为可点击卡，也不应出现“换一批/冷热”等轮换控件。
- [ ] 点击“青石镇”，触发“镖局急帖”，选择接下悬赏后获得 `ch1_bandit_notice_taken` 对应进度；回到地图并推进时段。
- [ ] 点击“黑松林”，触发“劫匪踪迹”，选择追查/磨练后进入或结算第一章劫匪进度；回到地图后下一步指向青石镇。
- [ ] 点击“青石镇”，触发回城交差添装事件；确认获得粗铁剑、麦粉、山泉水等破庙前置资源。
- [ ] 打开行囊/烹饪，制作“蒸饼”；打开卡组/装备，装备“粗铁剑”。
- [ ] 等到夜晚后，“破庙”可见并显示主线引导；未到夜晚、未装备粗铁剑、未备蒸饼时应显示明确阻断原因且不消耗体力。
- [ ] 夜探破庙并进入黑市小头目战；胜利结算后回到地图，日志提示第一章完成，并获得血河残页相关进度。
- [ ] 第二章目标指向茶馆；点击“茶馆”触发残页墨痕来源事件。
- [ ] 第二章下一步指向黑松林；点击“黑松林”触发血河失控者/异动观察事件。
- [ ] 夜晚点击“破庙”，触发血河祭坛事件；选择研读/破坏后获得 `blood_altar_disrupted` 对应进度。
- [ ] 第三章目标指向青石镇；点击“青石镇”触发血玉残片追查事件。
- [ ] 第三章下一步指向黑松林；点击“黑松林”触发截击血河余党事件，并获得完整卷轴相关进度。
- [ ] 终局目标指向茶馆；点击“茶馆”触发最终抉择。
- [ ] 选择封印血河经后进入结局页，结局为“正道初兴/封印血河”方向；日志与结局文本正常显示。

## 重点反查

- [ ] 地点卡不会让玩家白白消耗体力：不可触发地点隐藏或禁用，并给出具体提示。
- [ ] 第一章后第二章地图引导不能消失；茶馆、黑松林、夜晚破庙应按顺序给出主线提示。
- [ ] 烹饪和装备前置不应把粗铁剑放回战斗卡组，也不应消耗错误物品。
- [ ] 战斗结束后应清理 `currentCombat/currentEventId/currentLocationId`，回到地图继续主线。
- [ ] 完整通关过程中无白屏、控制台错误、卡死在事件页或地图无可点主线地点的状态。

## 自动化对应

- 全量测试：`npm test`
- 生产构建：`npm run build`
